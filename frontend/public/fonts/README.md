# Fonts

`Metal-Mania-Regular.ttf` and `Trueno-Round-Bold.otf` are genuine SIL Open Font License
fonts ([Metal Mania](https://fonts.google.com/specimen/Metal+Mania) is a Google Font;
Trueno Round Bold's OFL terms are recorded separately) and are committed here.

`Eternal.ttf` isn't used in the app at all — it has no digit glyphs, and the app's UI
is dense with numbers (weights, reps, dates) almost everywhere text appears. It's used
on the website instead, where the only place it appears (`.eyebrow` labels) is a small
set of static, letters-only strings under full control. See `website/fonts/README.md`.
